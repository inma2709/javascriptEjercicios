5. Comprueba tu programa

Crea un archivo llamado script.js y escribe el código necesario para:

  1. Declarar las variables.
  2. Realizar los cálculos matemáticos.
  3. Comprobar las condiciones de descuento.
  4. Mostrar los resultados en los elementos HTML correspondientes utilizando getElementById() y textContent.
  5. Comprobar los resultados en la consola mediante console.log().

Los importes deben mostrarse como números y los descuentos como true o false.

Importante: todavía no tienes que calcular cuánto dinero se descuenta. Solo debes comprobar si el cliente cumple las condiciones de cada promoción.
